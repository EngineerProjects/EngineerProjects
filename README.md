## What I build

I design **governed AI agents** and the systems around them: agent runtimes, retrieval over private documents, automation connected to real tools, and the data pipelines underneath. I work in Go, Python and TypeScript.

My main project is **Seshat**, an open-source agent runtime written in Go, with a terminal interface, a desktop app and a multi-tenant cloud product built on it.

<p align="center">
  <img src="https://raw.githubusercontent.com/KPO-Tech/seshat-runtime/main/docs/images/seshat-demo.gif" alt="Seshat delegating a task to five sub-agents in the terminal" width="760">
</p>

| Project | What it is |
|---|---|
| **[Seshat Runtime](https://github.com/KPO-Tech/seshat-runtime)** | Open-source Go agent runtime: tools, sandboxed bash, MCP, RAG, 15+ LLM providers, terminal interface, gRPC and Go SDK. |
| **[SeshatOS](https://github.com/KPO-Tech/SeshatOS)** | Local-first desktop app and backend built on the runtime (in development). |
| **[tech-watch-agent](https://github.com/EngineerProjects/tech-watch-agent)** | Multi-agent research and technology watch platform: LLM orchestration, semantic search, web aggregation, automated reports. |
| **[job-hunting-skills](https://github.com/EngineerProjects/job-hunting-skills)** | AI-assisted job hunting skills for Claude Code and MCP runtimes: browser automation, CV adaptation, application tracking. |
| **[LocalIngest](https://github.com/KPO-Tech/LocalIngest)** | CLI and terminal UI that turns a repository into a Markdown report for documentation or LLM ingestion. |

Install Seshat in one command: `curl -fsSL https://raw.githubusercontent.com/KPO-Tech/seshat-runtime/main/scripts/install.sh | bash` (Windows: see the [installation guide](https://seshat-ai.com/en/docs/getting-started/installation)).
